#### 5.4.1 注入约定（console → 屏幕状态 → 断言 → 截屏）

注入以「console 命令 → 与物理输入同层的动作函数 → 状态层 → 渲染」为准，脚本化验证一律走这条链路：

| 命令 | 语义 |
|---|---|
| `UI <play\|tracks\|step\|transport\|global\|fx\|sound\|sample\|dsyn\|fm6p\|projects\|presets\|song\|system\|mod\|scale\|voice\|tools>` | **同步**切页（内部取 LVGL 锁；成功后作废待执行的异步切页邮箱，回显页即落地页）；`analog` / `fm6` 是 `sound` 的 console **别名**（P4-F Task 5：独立 FM6 页删除、ANALOG 页改为通用引擎页 SOUND，三者都回显 `UI page=sound (6)`；页 id 7 是空位，`UI 7` / `UI unused` 回 `UI ERR not_registered 7`）；无参打印当前页；页 id 合法但未注册回 `UI ERR not_registered <id>`（`projects`/`presets`/`song`/`dsyn`/`fm6p`/`system`/`tools`（P4-F Task 6，id 18）已注册且都是实体页，正常不会出现该令牌）。页签是**两行**（P4-B Task 11 / P4-C Task 11 / P4-D Task 8，ADR-005）：上行 9 组签 PLAY/TRACKS/EDIT/MIX/SYNTH/SEQ/SONG/FILE/SYS（P4-F Task 4 起 104px 宽；无已注册页的组不显示）、下行当前组子签；**组作用域**——跨组切换的顺序是「建目标页 → 切到目标页 → 销毁源组全部已建页（含原当前页）」，故 `UI` 到另一组后源组 `built=0`，同组切页只改显隐。`UI QUIESCE <on\|off>` 手动复验诊断期静默（暂停/恢复 30ms UI 定时器、LVGL 定时器、触摸 indev 与输入派发），与 `ENG SELFTEST` 内部同入口。注意手动 `on` 不是粘滞的：下一次 `ENG SELFTEST` 会自行 on→off 并在结束时恢复（等价于一次 `off`），自检结束后需重新手动 `on` 才能复验拒绝路径。**失败令牌**：取 LVGL 锁超时回 `UI QUIESCE <on\|off> ERR lock_timeout quiesced=<0\|1>` 并返回非零（on 失败 = 输入静默已回滚、UI 仍在跑；off 失败 = 保持静默态，可重试）；`ENG SELFTEST` 在 on 失败时回 `cases=0 result=FAIL reason=quiesce` 且**不冻结引擎** |
