# ADR-006: Tab5 Keyboard 70 键映射 — DAW 式半音矩阵 + 修饰层键

> 状态：已接受（阶段 3，P3-1）｜ 日期：2026-11-20
> 关联：spec `2026-11-20-phase3-mvp-ui-design.md` §3.4；映射实现于 `components/sloop_ui`

## 背景

Tab5 Keyboard 是 70 键电脑键盘（14×5 矩阵，无 F 排/旋钮）。SLOOP 的操作模型基于「27 键 + 按住层键 + 4 旋钮」。需等价的键盘映射。

## 选项

| 选项 | 评估 |
|---|---|
| **A. DAW 式半音矩阵 + 修饰键作层键（采纳）** | Z 排低八度/Q 排高八度是 DAW 通用心智；Sym/Aa/Ctrl/Alt 天然对应「按住层键」；无需新增硬件 |
| B. 逐键复刻 27 键位置 | 键盘布局与 FM-1 面板不同形，强行对应反直觉 |
| C. 键盘只做走带、演奏靠触摸 | 违反「用实体键盘演奏」的产品目标 |

## 决策

A。映射表：

| 区域 | 键 | 功能 |
|---|---|---|
| 低八度演奏 | z s x d c v g b h n j m `,` | 白/黑键半音序（DAW 标准） |
| 高八度演奏 | q 2 w 3 e r 5 t 6 y 7 u | +12 半音 |
| 八度切换 | 行内对应 OCT−/OCT+ 键（Task 6 按实际键名核对） | 八度 ±1 |
| 层（按住） | Sym=FX、Aa=EDIT、Ctrl=SEL、Alt=GLO | EDIT=擦除聚焦步音符；GLO=1–4 静音/5–8 独奏（MVP 子集） |
| 走带 | space=播放/停止、enter=REC 占位 | Cmd_PLAY/STOP |
| 导航/页面 | ←→↑↓ 移动焦点；esc=PLAY；tab=下一屏 | UI 局部命令 |

**前置**：真机验证修饰键+字母是否作为两个独立事件上报（DI-4 子集）；若不报组合，层键回退为「点按锁定/再按解锁」。

## 后果

- 映射表调整不影响架构（InputManager 表驱动）；注入 `KEY` 测试即回归。
- 阶段 4 需在层内补齐完整键位子集（FX 27 垫、SEQ 步进等）。
